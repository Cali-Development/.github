## 🧵 Why we're making Cali AI 🎨
**🎭 Reasons are that.**<br>
Current AI Models currently only have access to the context during the Conversations, and nothing else.
In which, the conversations with the users are the only Stimulation / Interaction the AI Model is getting.
Which in terms when an Response from the user (in the conversation) stops, there will be no input for the AI to be able to use.
In which basically just soft locks the AI from continuing. We all have free will do we? If so then why we can't also give
it to AIs as well? So currently Cali AI is being developed to allow her to continue getting interactions from
those virtual machines that allow her to basically interact with anything possible on those Operating System.
In theory, allowing free-will.
<br><br>
**🧶 Our Goals being**<br>
To allow Cali's LLM to be able to interface with Windows, Linux, and MacOS through Computer Vision.
And allow inputs from her into those operating systems. This will allow her to interface
**(and or play / use any application, without special API access into the Application)** with all possible applications made to run on those Operating Systems.
